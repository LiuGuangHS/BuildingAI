# Security Policy

## Supported versions

Security fixes are prioritized for the latest published release and the `master` branch.

## Reporting a vulnerability

Do not report vulnerabilities in a public issue, pull request, discussion, or chat message.

If GitHub private vulnerability reporting is enabled for this repository, use its private reporting form:

https://github.com/LiuGuangHS/BuildingAI/security/advisories/new

If private vulnerability reporting is unavailable, contact the repository maintainers privately through GitHub before sharing technical details.

Include the affected version or commit, reproduction steps, impact, and any safe proof-of-concept details. Do not include real credentials, API keys, personal data, or production data.

## Disclosure

Please allow the maintainers to investigate and prepare a fix before publicly disclosing the vulnerability. The disclosure timeline will be coordinated with the reporter based on severity and operational impact.
